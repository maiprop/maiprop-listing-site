Auth Flow

flowchart TD SB[Supabase Auth] -->|onAuthStateChange| AC[AuthContext] AC --> SESSION[session JWT] AC --> PROFILE[profile\nrole · participant_type\ninvestor_mode · kyc_status] AC --> SUB[subscription\ncheck-subscription fn\npoll every 5min] SESSION -->|no session| LOGIN[→ /login] SESSION -->|needs onboarding| ONB[→ /onboarding] AC --> PR[ProtectedRoute\nrequires login] PR --> SR[SellerRoute\nisSellSideRole\nagent · seller_landlord\ndeveloper · institutional] PR --> IR[InvestorRoute\nuseEligibleForQuickSale\nverified + POF + subscription] PR --> AR[AdminRoute\nisPlatformAdmin\nrole=admin OR is_platform_admin] style AC fill:#1f2560,stroke:#3ef0d8,color:#e8ecff style SR fill:#2a1d3d,stroke:#9b6dff,color:#e8ecff style IR fill:#0f2d20,stroke:#34d399,color:#e8ecff style AR fill:#2d0f18,stroke:#fb7185,color:#e8ecff

AuthContext state

  • session — Supabase JWT session
  • user — Auth User object
  • profile — DB row from profiles table
  • subscription — tier, productId, subscriptionEnd
  • needsOnboarding — redirects new users
  • loading — unblocks UI after 8s safety timer

Guard summary

  • public — No auth required
  • auth — Requires login + onboarding complete
  • seller — Requires sell-side role
  • investor — Verified + active sub + POF approved
  • admin — Platform admin flag or role
